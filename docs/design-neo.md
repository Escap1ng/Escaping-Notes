# Escaping Notes · 新版设计文档（neo · 多普勒坠入 DOPPLER DESCENT）

> 2026-09 起生效，取代 Aurora Glass 方案。本文是新版皮肤（`data-skin='neo'`，默认皮肤）的唯一设计依据；旧版（legacy 皮肤）设计见 [design.md](./design.md)，两者互不覆盖。

## 1. 核心概念（≤200 字）

首页是一枚真实可交互的黑洞：文章是绕它公转的天体，点中即坠入。全站色彩取自多普勒效应——迎面而来者蓝移（交互），背离而去者红移（深度），白只留给光子环。滚动即向事件视界下潜：晕影收紧、深度轨转暖、转场向奇点坍缩。每一页背景沉着一枚巨型幽灵汉字，是创作者的签名。

访客一句话复述：**"这是一个把博客做成黑洞的网站，文章在轨道上公转，滚动就是往下坠。"**

## 2. 两个核心装置

### 2.1 可交互黑洞（`components/neo/BlackHole.vue`）

- **渲染管线 v2（Canvas 2D，逐帧）**：离屏层 L（光晕+透镜环带）、D[]（三层差旋盘纹理，`ω∝1/r^1.5`，离线预渲染）、F（当帧盘合成帧）、starSprite（星光辉光精灵）。多普勒染色用屏幕空间 `source-atop`（只染盘像素，透明区不泄漏）+ `blur(1px)` 柔化丝状条纹。
- **遮挡顺序**：星场（透镜偏折）→ L → 盘后半（clip 上半，暗、红移）→ 阴影+白热光子环 → 盘前半（clip 下半，亮、蓝移）→ 轨道节点。
- **交互**：滚轮/滚动 = 吸积盘倾角开合（`tilt = 0.5 + k·0.85`，固定偏航，不随鼠标）；最新文章为轨道节点公转，悬停放大辨认，点击坠入文章；点空白处 = 一圈引力波涟漪。
- 非交互模式为全站固定星场背景。DPR≤2、rAF 单循环、`visibilitychange` 暂停、reduced-motion 静态单帧。
- 已移除：长按投喂、首屏轨道读数条（保持首屏只有星与联句）。

### 2.2 红移坠入（Redshift Descent）

- 滚动 = 下潜，深度 `p∈[0,1]` 由 `DepthRail.vue` 写入 CSS 变量 `--shift`，驱动：暗角晕影加深、深度轨刻度由冷漂暖、首页宣言字距被潮汐力拉长。
- `DepthRail.vue`：右侧可点击深度刻度列（悬停展开栏目名 + 发光头标），全站唯一半径比读数处；玻璃读数面板已移除，只留极简刻度。
- **fall 转场**：路由跳转 = 向奇点坍缩（scale .8→1、blur 12→0、红移滤镜）→ 展开成新页。全站唯一转场。
- 文章页时间膨胀读数：`τ/t = √(1−1/r)`——"你在此处停留的光阴，比人间慢一拍"。

## 3. 视觉语言：多普勒双色系统

| 令牌 | 深空 | 纸面（白矮） | 分工（严格不混用） |
| --- | --- | --- | --- |
| `--cold` | `#8ec9ff` | `#2563eb` | **交互**：hover / 链接 / 焦点 / 轨道节点 / 光标 caret |
| `--hot` | `#ff5c39` | `#c2410c` | **深度**：进度 / 深度轨 / 当前项 / 日期 |
| `--white` | `#fff7ed` | `#7c2d12` | 仅光子环与高光 |

- 底色：近纯黑深空（`--ink-0 #020204`）；`--hole` 供日食式镂空（黑洞阴影与页面同色），`--scrim` 为文字径向底衬。
- 字体三层：衬线碑刻标题（display）/ 宋体正文（serif）/ 等宽读数（mono），零 webfont。
- 幽灵汉字签名：坠（首页/文章页）、盘（归档）、脉（动态）、振（歌单）、抛（项目）、回（留言）、我（关于）、无（404）。
- 光标系统（neo.css）：正文 `default` 且 caret 透明（点击不出现插入竖线）；链接/按钮 `pointer`；输入框 `text` + 冷色 caret。
- 标签页图标：透明底镂空彩色圆环（四段蓝→红→白渐变）。

## 4. 文案层（`src/config/narrative.js`）

新版所有界面文案唯一来源；旧版与 `site.js` 不受影响，新版界面不出现「井」隐喻。文风：简易两字词为骨、对偶联为魂（首页宣言"掷墨入渊，星惊不复；藏光于页，潮退犹闻"）。署名统一 **Escap1ng**（观星手记 / 仍在坠入）。

## 5. 双皮肤架构（neo / legacy）

- 状态：`src/lib/skin.js`（`reactive({mode})` + `applySkin/toggleSkin`），键 `localStorage['en-skin']`，默认 `neo`；`index.html` 首帧内联脚本写 `<html data-skin>` 防闪烁。
- 路由：`src/router/index.js` 的 `skinned(legacy, neo)` 包装器（`defineAsyncComponent` ×2 + 渲染函数按 `skin.mode` 选择），九条访客路由双皮肤；`/fragments /login /register /admin` 仅旧版组件。切换无需刷新。
- 壳层：`App.vue` 按皮肤选择 Header/Footer，并条件渲染 neo 专属层（`BlackHole` 固定星场、`.neo-vignette`、`DepthRail`）；转场名 `fall`(neo) / `orbit`(legacy)。
- 样式分层：`src/styles/neo.css` 全部规则以 `html[data-skin='neo']` 网关（特异性压过 tokens.css），并重定义旧变量名使沿用旧组件的页面自动协调；`data-skin='legacy'` 时本文件全部失配，旧版零回归。
- 闭环按钮：neo 头部「显示旧版界面」、legacy 头部「显示新版界面」。

## 6. 页面要点

- **首页**：`HorizonHero.vue` 排版层（eyebrow + 对偶联宣言 + 副句 + 「现在」三栏在写/在听/在做）浮于黑洞之上，左下 `--scrim` 径向底衬保证可读；首屏视差随滚动下沉淡出。
- **文章归档 `/blog`**：大框体卡片列表——窗口足够（>880px）时一行两篇，不够时一行一篇；卡片含日期（红移）/ 标题 / 摘要三行截断 / 字数时长与标签脚线；hover 边框蓝移 + 聚光（`neo-lens`）。
- **文章页 `/blog/:slug`**：衬线长文（`--measure` 限宽）+ 时间膨胀读数 + 更浅处/更深处翻页。
- **动态/歌单/项目/留言/关于**：统一 eyebrow 编号 + 幽灵字 + 极简列表/时间线；空态文案见 `N.empty`。
- **404**：「已越事件视界」。
- 浅色主题为「纸面」：同套双色逻辑，色相换为纸感暖白 + 深蓝/赭红。

## 7. 与初版方案的差异备忘

- Aurora Glass（星云玻璃/Bento/视差装置）整体废弃，仅保留双皮肤机制。
- 长按投喂、首屏轨道读数条、深度轨玻璃读数面板：实施后按反馈移除。
- 环倾角只随滚动开合，不随鼠标（初版曾做指针倾角）。
