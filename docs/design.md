## 1. 核心概念（核心隐喻，≤200 字）

本站是一张逃逸轨迹图。日常是引力井，每条笔记都是一次逃逸：首页井底，粒子沿轨迹挣扎上升；光标是干扰引力，使轨迹弯曲；滚动是爬升，读数 ALT 升高、VEL 逼近逃逸速度。文章是已入轨的卫星，留言是访客投进井里的信号。视觉是仪器面板：墨蓝底、夜视琥珀为唯一信号色、等宽字作读数。交互即逃逸动力学：悬停干扰、长按蓄能、点击入轨。

访客一句话复述：**“这是一个把博客做成引力井的网站，每篇文章都是一粒逃出日常的粒子，我的鼠标就是干扰引力。”**

## 2. 体验路径（开始 → 发展 → 转折 → 收束）

| 阶段 | 位置 | 发生什么 |
| --- | --- | --- |
| 开始 | 井底视场 | 读数逐条点亮（LOC 坐标 / T 本地时间 / ESC 11.2 KM/S）；粒子沿轨迹缓慢上升、轻微颤动；光标引力干扰即刻可玩（轨迹弯曲、粒子偏转点亮）。3 秒内建立记忆点。 |
| 发展 | 滚动爬升 | ALT 读数上升；星层与轨迹分层下退（视差=我们在上升）；五个逃逸坐标（文章/动态/收藏/留言墙/关于）按序点亮，轨迹线连向坐标，连线伴随读数跳字。 |
| 转折 | 点击坐标 → 进入页面 | 粒子“入轨”：轨迹收拢成环（全站唯一转场），目标页从环心展开。文章页色温由“爬升模式”（墨蓝）微移向“入轨模式”（纸感暖白阅读栏）——逃逸成功、进入记录的安静，不是换了一块无关的页面。 |
| 收束 | 页脚逃逸日志 | colophon 一行 “继续逃逸”；留言墙的访客信号作为井外投来的收束笔触。 |

### 隐藏微交互（需主动探索）

1. **蓄能**：首屏按住鼠标/触摸 ≥800ms，粒子加速发亮、VEL 读数爬升；逼近 11.2 时浮现一句隐藏文案（“已达到逃逸速度，井外见。”），松开缓慢回落。
2. **共振**：连点 logo 三次，全部轨迹同相位重排，读数显示 `SYNC OK`。

### 核心体验装置（必做项对照）

- 视觉与交互的中心锚点：引力井轨迹场（canvas 2D）。
- 连续反馈：光标引力弯曲（轨迹曲率+粒子亮度随距离连续变化）、滚动爬升、坐标连线进度。
- 自己的运动逻辑：粒子带“挣扎感”上升（慢-快-慢+颤动），弹簧阻尼跟随光标，非单次播放。
- 与概念直接相关：轨迹=逃逸，海拔=阅读深度，入轨=打开文章。
- 超出常规 Landing Page：整站导航内嵌在轨迹场中作为“逃逸坐标”，而非悬浮菜单。

## 3. 视觉原则

- **色彩**：墨蓝灰阶（`--ink-*`）+ 唯一信号色夜视琥珀（`--signal: #ffb454`）。依据：琥珀既是仪器信号色，也暗示引擎尾焰——墨蓝夜空中唯一的暖光源，“正在工作、正在逃逸”的语义，不是装饰霓虹。
- **双主题（井底/井外）**：井底=夜航墨蓝，“正在逃逸”；井外=纸感暖白，“逃逸后的档案”，轨迹场在井外呈现为纸上墨线航迹图。切换是叙事行为（一次逃逸/一次下井），不是换皮肤；头部读数式开关 `LOC: 井底/井外`，localStorage 记忆。井外信号色改用赭琥珀（#b45309）保证纸面可读性。
- **字体**：三层系统字体栈——等宽（仪表读数）/ 宋体衬线（标题与记录正文）/ 无衬线（UI 控件）。零 webfont，层级靠字号、字重、字距建立。
- **材质**：发丝线（1px `--line`）、读数、网格留白。无阴影、无浮起卡片、无渐变玻璃。
- **节奏**：动效必须有物理量（弹簧阻尼、惯性、蓄能积累）；没有被干扰时，页面保持安静。

## 4. 交互原则

- **逃逸动力学**，全站统一动词：悬停=干扰（轨迹弯曲）/ 长按=蓄能 / 点击=入轨（进入文章）/ 离开=回落安静。
- 转场只有一种：入轨收环 → 展开（状态延续，非区块拼接）。
- 键盘：逃逸坐标即路由链接，Tab 可达、Enter 打开；首页保留“逃逸目录”列表作为键盘与降级入口。
- `prefers-reduced-motion`：轨迹场渲染为单帧静态轨迹图，导航回落到目录列表；全局动画关停（已在 tokens.css 实现）。
- 移动端：触摸拖动=干扰引力移动，长按=蓄能；粒子数与 DPR 上限下调保帧率。

## 6. 主动“不做”的三件事

1. **不做玻璃拟态 / 渐变卡片 / 阴影浮层。** 理由：仪器的质感来自发丝线、读数与留白；浮起卡片会把“逃逸面板”叙事稀释成模板感仪表盘。
2. **不做 opacity+translateY 批量滚动 reveal。** 理由：动效必须源自逃逸状态（干扰、蓄能、入轨、连线）；批量 reveal 与概念无关，是模板感的首要来源。
3. **不引入外部字体 / CDN / 任何密钥服务。** 理由：保证本地离线与生产构建双可运行、加载快、无隐私依赖；天气等需密钥的功能一律以“本地读数”语义替代。例外条款：登录/文章/留言墙依赖自托管零依赖后端（自有服务器、不依赖第三方），见 §7；后端缺席时站点保持完整只读降级。

## 7. 技术选型

- **Vue 3 + Vite + Vue Router**（用户指定 Vue；Vite 构建快、配置少）。
- **canvas 2D 轨迹场**（粒子+贝塞尔轨迹），不引 three.js：装置是 2D 视差+引力位移，2D 足够；包体小、降级简单、移动端帧率可控。
- **Markdown**：阶段二引入轻量解析（frontmatter 自解析 + 小型渲染器或 marked），不引重型 SSG。
- **存储**：跨设备共享数据走自托管极简 API（JSON 文件）；API 不可达时 localStorage 降级；无第三方服务、无密钥。
- **双主题架构**：颜色全部走 CSS 变量，`:root[data-theme='out']` 覆盖；阶段一 canvas 统一用 `getComputedStyle` 读取变量取色，双主题零额外成本。
- **部署硬约束（2核2G 服务器）**：nginx 托管 `dist` 即运行，内存 <10MB、CPU 近零。部署步骤见手册 §4.3。
- **公开形态**：自有域名 + HTTPS + 备案（大陆服务器）为主方案；Vercel/GitHub Pages 仅作只读镜像（登录/留言自动禁用）。`data/` 目录=整站数据，备份=复制。测试期先托管 GitHub Pages（仓库 `Escap1ng/Escaping-Notes`，Actions 自动部署，`--mode pages` 启用 base 与 hash 路由），域名就绪后切主方案。
- **公开呈现（SEO/OG/RSS）**：后端对文档路由做 meta 注入（index.html 占位改写），链接预览与爬虫拿到真实 meta；RSS 发文时写出；`site.url` 为 canonical/OG/RSS 的唯一来源。
- **自托管极简后端（必需组件）**：`server/api.py`，Python3 标准库单文件、零安装、零依赖；JSON 文件存储，无数据库；仅监听 127.0.0.1:8787，nginx 反代 `/api/`；内存约 20MB；内置限流与长度限制。前端任何情况下 API 不可达即降级只读/本地模式，站点永不报错。
- **鉴权与角色（标准库实现）**：密码 `hashlib.pbkdf2_hmac` 加盐哈希，不存明文；会话=`secrets` token+过期；注册/登录限流。三角色：访客（注册）/管理员/站长；首跑无账号时前端引导初始化站长；管理员由站长任命。
- **文章事实源统一**：服务器 `data/posts/*.md` 为唯一事实源（站长网页编辑器写入，或手动投 md 文件）；本地 `content/posts/` 仅作开发种子与离线回退。
- 性能：DPR 上限 2；粒子数随面积缩放（桌面≈180 / 移动≈90）；`visibilitychange` 暂停渲染循环。

## 9. 创意总监自审清单（构建期使用）

1. 概念贯穿：每个页面是否都有读数/发丝线/逃逸动词？
2. 模板感：是否存在可以原样换到别的网站的区块？
3. 无意义动效：是否存在与逃逸状态无关的动画？
4. 首屏记忆点：引力干扰是否 3 秒内可感知？
5. 信息易懂：首次访客能否 10 秒内看懂站点内容（目录列表兜底）？
6. 移动端：单手是否可操作，干扰是否触摸可用？
7. 性能：LCP < 2s、轨迹场帧率稳定、无外部请求？
