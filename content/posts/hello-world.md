这是本站发出的第一篇，原来兼作使用说明。使用部分已经搬去「网站使用说明」那一篇，这里只留理念——顺便留着当 Markdown 写法的样板。

## 概念：写作即一次长曝光

北半球的一夜长曝光是这样的：相机架在三脚架上，快门长开，恒星绕着天极缓慢走过，底片上留下一条条同心弧——时间本身被写下来的样子。写作在我眼里是同一件事，所以首页就是这台相机：数百条弧绕一枚天极**刚体旋转**累积，基础角速度 `OMEGA = 0.042 rad/s` 全场一致，恒星周日视运动是统一的那一层时间流速。文章不挂在星星上（那是上一版的装置，已撤），入口在折线以下的抽屉里。

## 五条原则

出自 `docs/design.md` §2，所有后续决策都要遵守：

1. **冷暖分工，严格不混用**。`--cold` 只给交互（链接、悬停、焦点、星轨节点），`--hot` 只给深度与强调（进度、日期、当前项），`--white` 只留给星核与 2px 以内的高光。
2. **主题是叙事，不是皮肤**。切换主题 = 一次夜拍（深色，星轨以 `lighter` 加色发光）或一次显影（浅色，墨以 `source-over` 压在干版上）。任何新增样式必须在两套主题各看一遍。
3. **深度 = 时间**。滚动把 `--shift`（0..1）写进 `<html>`，驱动晕影收紧、首页标题字距拉长、曝光窗口变长、天空转快。凡"随滚动变化"的视觉都挂这一个值，不允许各自再写一套滚动监听。
4. **文案唯一来源是 `src/config/narrative.js`**。界面只说人话——按钮、眉标、提示、空态一律直陈其物；隐喻只留在两处文学位（首屏十六字与关于页自述）。
5. **可降级**。一切动效都要有 `prefers-reduced-motion` 下的静态出口；API 不可达时站点仍是一份完整的离线底片。

## 一条位置协议：暗带

文字底下的天空由**全站一处**压低，不外包给卡片背景。几何是 `neo.css` 的 `--sky-band` / `--sky-feather`（带内全压、到视口边缘羽化回全亮），压低系数按主题各给一档 `--sky-k`：深色 0.15、浅色 0.06——浅色比深色严 2.5 倍，因为那里压的是接近纯黑的墨迹。三者关系收敛成一句话：**暗带管"读得清"，卡片管"是一组"，文章页那块玻璃底板管"长时间阅读时的隔离"**。

## 一张卡面，一组刻度

`.neo-card` 是全站唯一的卡片表面——边、角、底、hover、内边距、210px 最小高全部取自 `--card-*`。栅格可以不同（`.neo-cards` 两列、`/blog` 三列、首页精选三格），卡面不许另造。尺寸全部走刻度：间距 `--space-0…5`、字号 `--fs-3xs…4xl`（最小一档 11.5px，仪器文字再小就不可读）、行高 4 档、字重 3 档。组件内不写裸字号、不写裸间距。

## 底片不重铺

最贵的一处资产：底片跨路由常驻，`src/lib/sky.js` 以单例接管画布（`claimPlate` / `ownsPlate` / `releasePlate`），换页不重置星轨——你翻过的每一页都算进这一夜的曝光。代价是像素预算：`MAXPX = 9e6` 封顶，超了就自动降 DPR，下限 `MIN_DPR = 1.8`。

## 样板：格式示例

正文里可以放代码块：

```js
// 第一缕信号
console.log('hello, observer')
```

也可以放引用：

> 光在底片上走了整整一夜，才显出这一道弧。

你在往上翻的时候，我在往下写。你此刻读到的这一页，是这一夜曝光里留下的一道弧光。
