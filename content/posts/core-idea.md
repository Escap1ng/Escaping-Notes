掷墨入渊，星惊不复；藏光于页，潮退犹闻。这句话是 Escaping Notes 的全部起点——本站不是"一个带特效的博客"，而是一次持续的长曝光：每一个界面、每一次交互，都服务于同一片夜空。

## 隐喻：写作即曝光

你看过北半球的一夜长曝光吗？相机架在三脚架上，快门长开，恒星绕着天极缓慢走过，在底片上留下一条条同心弧——那是时间本身被写下来的样子。写作在我眼里就是这样：把一段流逝的日子，稳稳地摁在底片上，用一整夜的光去显影。于是首页被做成一架长曝光的相机：数条同心星轨绕着一枚偏心天极匀速累积，文章是定点脉动的变星，动态是周期脉冲，留言是落在夜幕上的回声。你打开本站，不是访问一个网站，是走进我这一夜的取景框。

## 交互：时间流速，而非点击

装置不是装饰，交互即物理：

- **滚动 = 时间流速**：下潜越深，曝光窗口越长、天空转得越快——你能"看见"这一夜在加速；
- **悬停 = 变星绽放**：文章化为一颗颗变星，驻目便绽开锥形衍射十字芒，主芒长、副芒短，沿芒长渐隐，像望远镜口径里析出的光；
- **指针 = 引力时间膨胀**：光标半径内星轨局部加速卷曲，如同光绘 torch 扫过夜空——你的靠近本身就在扭曲这一段时间；
- **点击变星 = 入文**：命中即坠入正文，页面转场是一次向下的坠落，再展开成新的星图；
- **流星 = 环境叙事**：偶有流星划过底片，一闪即逝，不必解释。

没有为动效而动效。所有反馈都是这个画面的延伸，删掉任何一条，叙事就缺一角。

## 视觉：深空与纸面

色彩系统取自夜空的两副面孔。深空主题下，星轨是冷白、暖白与琥珀三档色温，用 `lighter` 混合出真实的发光感；纸面主题则是一张天文干版底片——墨与 sepia 的轨迹之上，只有朱砂一点点睛。两种信号色贯穿始终：**冷色**负责一切"与你互动"的东西（链接、悬停、光晕），**暖色**负责一切"时间沉淀"（进度、当前项、轨迹），白色只留给高光。排版上，正文用衬线，是"记录"的温度；读数用等宽，是"仪器"的冷静。每一页背景里还藏着一枚巨大的幽灵汉字——渊、藏、坠、息、弦、掷、响、我——不解释，看见了就算打过招呼。

## 工程：手工建造，零依赖

前端 Vue 3 + Vite，后端是单个 Python 标准库文件：没有框架堆叠，没有第三方 UI，没有 webfont。整片星空由 Canvas 2D 逐帧绘制——离屏累积缓冲模拟长曝光底片，每帧先做 `destination-out` 衰减再做短弧增量沉积，尾迹自然累积；像素预算封顶自动降 DPR，`prefers-reduced-motion` 下一次快进生成静态底片。文章、动态、歌单全部内容化，网页端 `/admin` 可改；API 不可达时自动降级为打包种子，镜像依旧可读。手工建造本身就是理念的一部分：这一夜的每一缕光，都是自己算的。

## 结语

你还在往上翻的时候，我已经在往下写。你此刻读到的这一页，是我这一夜曝光里留下的一道弧光；若它也让你想起自己头顶的那片夜空，欢迎在留言墙落一枚回声。
