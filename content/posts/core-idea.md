掷墨入渊，星惊不复；藏光于页，潮退犹闻。这句话是 Escaping Notes 的全部起点——本站不是"一个带特效的博客"，而是一次持续的下潜：每一个界面、每一次交互，都服务于同一个画面。

## 隐喻：写作即投渊

黑洞是宇宙里最诚实的比喻：进去的东西，从来不回来。过完的日子就是这样——沉下去，无声无息。而写作是我唯一确信的反抗：把一行字推过事件视界，它就从"会忘记的日常"变成"永在的记录"。于是首页被做成一枚黑洞：文章是绕它公转的天体，动态是周期脉冲，留言是落在视界上的回声。你打开本站，不是访问一个网站，是路过我的引力场。

## 交互：下潜，而非点击

装置不是装饰，交互即物理：

- **滚动 = 下潜**：页面随深度持续红移，暗角收紧，右侧深度轨冷色渐暖——你能"看见"自己在变深；
- **悬停 = 蓝移**：一切可交互的东西都朝你变蓝、变亮，你的靠近本身就在给场注入能量；
- **滚轮 = 开合**：在首页滚动滚轮，吸积盘从侧视缓缓张开到俯视——换一个角度看同一个渊；
- **点击轨道 = 入文**：轨道上的节点就是文章，命中即进入；页面转场是一次坠入——向奇点坍缩，再展开成新的世界；
- **落点无文 = 涟漪**：点在没有文章的深处，只泛起一圈引力波，随即归于平静。

没有为动效而动效。所有反馈都是这个画面的延伸，删掉任何一条，叙事就缺一角。

## 视觉：多普勒双色

色彩系统直接取自多普勒效应：迎面而来者蓝，背离而去者红。全站只有两种信号色——**蓝移冷色**负责一切"与你互动"的东西（链接、悬停、轨道节点），**红移暖色**负责一切"深度"（进度、当前项、坠入感），白色只留给光子环与高光。不混用，不越权，颜色本身就是信息。排版上，正文用衬线，是"记录"的温度；读数用等宽，是"仪器"的冷静。每一页背景里还藏着一枚巨大的幽灵汉字——坠、盘、脉、振、抛、回、我——不解释，看见了就算打过招呼。

## 工程：手工建造，零依赖

前端 Vue 3 + Vite，后端是单个 Python 标准库文件：没有框架堆叠，没有第三方 UI，没有 webfont。黑洞整枚由 Canvas 2D 逐帧绘制——差旋吸积盘、透镜光环、星场辉光，全部手写。文章、动态、歌单全部内容化，网页端 `/admin` 可改；API 不可达时自动降级为打包种子，镜像依旧可读。另外保留了一键切回旧版界面的开关——黑洞之下，那口旧井还在原地。手工建造本身就是理念的一部分：这个渊的每一缕光，都是自己算的。

## 结语

你还在往上翻的时候，我已经在往下写。你此刻读到的这一页，是我坠入途中抛还视界之外的一束光；若它也让你想起自己的那个渊，欢迎在留言墙落一枚回声。
